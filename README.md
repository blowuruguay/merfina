# Merfina

Sitio web de Merfina Joyas (cubre botones y corbatas).

## Stack
- Node.js + Express (static server)
- HTML / CSS / JS plano en `public/`
- Deploy: Railway (NIXPACKS)

## Dev local
```bash
npm install
npm start
# http://localhost:3000
```

## Estructura
```
merfina/
├── package.json
├── server.js
├── railway.json
├── .gitignore
└── public/
    ├── index.html
    ├── css/styles.css
    └── js/main.js
```

## Deploy
Push a `main` → Railway redeploya solo.
